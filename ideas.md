- A loupe plugin for showing the zoomed image where the mouse is
- Since Triiiceratops is lighter weight than even the Digerati canvas panel, this would be an interesting demo use case: using Triiiceratops as a single canvas viewer. We could probably use the content state to indicate a specific canvas. Then use the config to hide all viewer chrome, including making the canvas transparent. That would make it behave like an image tag to a sighted viewer. This also opens up an interesting way to highlight a manifest, but having multiple instances of Triiiceratops, one per canvas, on a page with content associated with each canvas, and each image deep-zoomable.

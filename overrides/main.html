This overrides base.html's own `htmltitle` block for ONE reason: that block branches on `page.is_homepage`, and Zensical 0.0.52 never populates that attribute — on any page, home page included. So the home page took the "subpage" branch and rendered "Triiiceratops IIIF Viewer - Triiiceratops IIIF Viewer" in the browser tab and in search results. Comparing the canonical URL to `site_url` is the same test and actually works; it also stays correct on a versioned build, where the site root is a version subdirectory. The same substitution is made in partials/social-meta.html, which needs the same fact for `og:type`.

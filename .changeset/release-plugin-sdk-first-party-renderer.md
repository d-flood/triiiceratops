**The raw OpenSeadragon viewer is no longer reachable from a plugin, and nothing replaces it as an object.** `whenOsdReady` is removed in favour of `whenRendererReady(state)`, a first-paint signal resolving `void` — there is no instance to hand over — and `setOsdViewer` is gone from the test kit. Most plugins need no readiness gate at all now: viewport commands are no-ops before a renderer mounts, the viewport queries answer `0` / `null`, and both `registerOverlayLayer` and `registerPaintLayer` accept registrations before one exists. A plugin reaches the image through core's own surface instead (`canvasToScreen` / `screenToCanvas`, the viewport commands and queries, `subscribeFrame`, `subscribeSurfaceTap`), so `requiredCapabilities` is normally `[]` and the retired `osd@5` fails activation by design. In its place the kit gains `context.attachRenderer({ canvasIds })`, which mounts the headless renderer stand-in core now ships: it records the viewport commands it receives, makes the `frame` cadence and the viewport queries exercisable with no DOM, answers `null` for any canvas you did not list — the honest-absence branch a real host follows for a canvas it has not laid out, and the one an overlay must handle — and drives selection through `emitTap` and repaints through `emitFrame`. Peers on the core release above.
